Домофон ПК 0.1.30 для Windows x64.

Распакуйте DomruDesktop-win-x64-0.1.30.zip и запустите DomruDesktop.exe. .NET runtime и видеодвижок включены.

Изменения: тестовое подтверждение открытия двери, статические статусы подключения, исправление перетаскивания развёрнутого окна, снимки в исходном разрешении PNG без служебного превью и пути.

Личные данные, сохранённые сессии, журналы и отладочные PDB не входят в дистрибутив. Кнопка открытия в тестовом вызове не управляет настоящим домофоном.

Приложение неофициальное. Доступность функций зависит от оборудования и API оператора.
